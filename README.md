### 💡 Turn Ideas into Impact.

**CodeForge '26 — Build. Innovate. Solve. 🚀**

# Functional Requirements

1. Student registration and login.
2. Daily 5-question wellbeing check-in.
3. Track sleep quality.
4. Track food/nutrition.
5. Track physical activity.
6. Track academic pressure.
7. Track social interaction.
8. Daily mood selection using emojis/rating.
9. Daily stress rating from 1–5.
10. Optional private daily notes.
11. Student dashboard with mood and stress trends.
12. View previous check-in history.
13. Detect high-stress patterns for 3–4 consecutive days.
14. Detect increasing/decreasing wellbeing trends.
15. Generate alerts for authorized staff.
16. Staff dashboard for flagged students.
17. Show alert reason and relevant date range to staff.
18. Protect private student notes from staff access.
19. Generate an automatic 7-day wellbeing summary.
20. Send daily check-in reminders.

# Non-Functional Requirements

1. Data privacy.
2. Secure authentication.
3. Role-based access control.
4. Data encryption.
5. Easy and intuitive user interface.
6. Daily check-in should take less than 1 minute.
7. Fast response and dashboard loading.
8. Reliable data storage.
9. No duplicate or lost check-in records.
10. Scalable architecture.
11. Maintainable and modular code.
12. High system availability.
13. Accurate trend analysis.
14. Explainable alerts.
15. Ethical and non-diagnostic risk classification.
16. Accessibility across devices.
17. Secure API and database communication.
