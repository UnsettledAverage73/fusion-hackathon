Complete Project Setup & Deployment Guide

Instructions for setting up the Fusion Hackathon Full-Stack Workspace on a new laptop (Windows, macOS, Linux).

1. System Prerequisites

Tool Minimum Version Command Check Notes
Git v2.30+ git --version Required for source control
Node.js & npm v18+ (LTS recommended) node -v && npm -v Runs Vite + React frontend
Python v3.12+ python3 --version Runs FastAPI backend
uv (Astral) Latest (Recommended) uv --version Blazing fast Python venv & package sync

2. Step 1: Clone the Repository

# Open your terminal or PowerShell and clone the repo
git clone https://github.com/UnsettledAverage73/fusion-hackathon.git
cd fusion-hackathon

3. Step 2: Backend Setup (FastAPI & SQLite)

The backend powers REST endpoints, JWT session security, Google Identity token verification, and real-time Slack alerting.

A. Copy the Environment Template

cd backend
# Linux / macOS:
cp .env.example .env

# Windows (Command Prompt):
copy .env.example .env

B. Install Dependencies and Run

Option 1 (Recommended & Fastest with uv):

uv sync
uv run uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

Option 2 (Standard Python venv + pip):

# Linux / macOS:
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

# Windows (PowerShell):
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
Backend Verification:
• Health Check: http://localhost:8000/health → {"status":"ok"}
• Swagger Docs: http://localhost:8000/docs

4. Step 3: Frontend Setup (React 19 + Vite + Tailwind CSS)

Open a second terminal window and follow these steps:

A. Navigate & Configure Environment

cd fusion-hackathon/frontend

# Linux / macOS:
cp .env.example .env

# Windows (Command Prompt):
copy .env.example .env

B. Install Packages & Start Vite Dev Server

# Install node modules
npm install

# Start development server
npm run dev
Frontend Access:
Open your browser to http://localhost:5173. The navbar will display Render: Online or local connection indicator.
